# E-commerce SQL Project

Welcome! This project demonstrates how SQL can be used to answer real-world business questions in an e-commerce setting. It showcases my skills in relational database design, data querying, and insights generation.

##  Project Overview

I created a sample e-commerce database and wrote SQL queries to solve common business problems such as:
- Identifying top customers
- Tracking product sales
- Analyzing revenue trends
- Finding frequently returned products
- And more...

This project is aimed at showcasing my **SQL proficiency** from **basic SELECT statements** to **complex JOINs, subqueries, and aggregation**.

##  Technologies Used

- **MySQL** (Database)
- SQL DDL/DML (for schema creation and data population)
- Git & GitHub (for version control)
